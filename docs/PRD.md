# 产品需求文档（PRD）· 闪取 SnapFetch

> 版本 0.2.0 ｜ 2026-11-06 ｜ 状态：已实现范围见每节标注
>
> 本文档是代码注释里 `PRD §x` 引用的出处。产品独立实现，与「云析 YunX」
> 及任何网盘官方均无隶属关系；功能形态对照官方移动端，代码独立编写。

## 1. 定位

把「别人分享的网盘链接」变成「本机高速下载」，不装各家客户端、不开各家会员。
桌面端形态：**Windows 10/11 x64 单平台**，其余平台不做。

- 使用者：自己用 + 开源给同类需求的人
- 商业性：不做商业用途、不收费、不带广告
- 边界：不破解付费内容、不共享账号、不绕过平台付费限制

## 2. 红线

### 2.1 产品红线（任何版本不得破坏）

| 编号 | 内容 | 违反后果 |
| --- | --- | --- |
| **C1** | 粘贴链接 → 必须能解析出文件列表 | 产品失去存在意义 |
| **C2** | 解析出的文件 → 必须能分片并发下载并支持续传 | 退化成浏览器下载 |
| **C3** | 免客户端直取：不得要求用户装官方客户端或开官方会员 | 与产品定位矛盾 |
| **R1** | 免登录可用的功能，不得把登录做成全局前置条件 | 用户第一次打开就被劝退 |
| **R2** | 用户设置的下载目录严格优先，绝不静默改存到别处 | 用户找不到文件 = 事故 |
| **R3** | 凭证只在本机 DPAPI 加密存储，绝不上传、绝不写日志 | 安全底线 |

### 2.2 合规红线

- 不复制上游项目代码；不打包任何平台商标图形（见 §12）。
- 尊重平台服务条款与 robots 边界，仅访问公开分享接口。
- 下载内容版权归原作者；文档明确「24 小时内删除」式自律提示。

## 3. 用户与场景

| 场景 | 谁 | 做什么 | 期望 |
| --- | --- | --- | --- |
| S1 | 拿到分享链接的人 | 粘贴 → 勾选 → 下载 | 30 秒内开始下载，速度跑满带宽 |
| S2 | 大文件/多文件分享 | 只挑其中几个 | 进入式浏览，跨目录保持勾选 |
| S3 | 需要自己网盘里的文件 | 登录后浏览自己的盘 | 直接下，不必去网页端 |
| S4 | 反复用同一批链接 | 收藏 / 翻历史 | 一键复用，不用重新找 |
| S5 | 不想污染自己网盘 | 免转存下载 | 不把别人的文件塞进我的盘 |

## 5. 平台范围

3 家网盘（夸克 / UC / 123 云盘）+ 2 家视频（抖音 / 小红书）。

视频平台**免登录**即可直出无水印直链与图集（红线 R1 的典型用例），
解析结果走 media_kit 在线播放 —— 这也是保留 media_kit（约 29 MB）的理由：
「先看再决定下不下」比「必须先下完才能看」省用户时间。

曾一度下架视频解析（收敛为纯网盘工具），随后确认播放是网盘工具的正经能力，
故恢复；接口反爬波动大是已知代价，失效时只改对应平台文件。

## 6. 关键交互

### 6. 结果呈现原则

解析结果只有两种形态：**文件树**（网盘）与**媒体集**（图集/视频，当前无生产者）。
UI 不为具体平台写分支，只认这两种形态。

### 6.4 下载目录

- 未设置：默认用户「下载」文件夹；写不了才退回程序目录 `downloads\`。
- 已设置：严格使用，失败就报错并说明原因，绝不改存。
- 分片临时文件写在程序目录（`sf-parts`），完成后合并到目标目录。

### 6.6 应用内登录

- 内嵌 WebView2 打开平台官方登录页，用户在页面内正常登录（扫码/短信/密码）。
- 点「完成」→ 经 CDP `Network.getCookies` 捕获全量 Cookie（含 HttpOnly）→
  按平台规则判定登录成功 → DPAPI 加密入库。
- 登录态在 `localStorage` 的平台（123 云盘的 `authorToken`）额外执行一次 JS 取值。
- WebView2 环境必须 `await create()`，否则 `userDataFolder` 失效会把
  Cookies 写进程序目录（差点被打包进分发包）。

## 7. 非目标与体积预算

- 便携包目标 **< 150 MB**（当前 Release 目录约 129 MB，zip 压缩后约 45 MB）。
- 不做安装包自动更新（GitHub Releases 手动更新即可）。
- 内存占用目标：空闲 < 200 MB。

## 8. 架构约定

### 8.3 解析器插件化

新增平台 = 新增一个 `LinkParser` 实现 + 在 `registry.dart` 注册，**核心零改动**。
需要登录才能浏览自己网盘的平台再实现 `CloudBrowser`。
平台接口字段变化只改对应平台文件，配套 fixture 测试守住请求构造。

## 9. 数据与持久化

全部为 JSON 文件，落在「探测到的第一个真实可写目录」（§9.2）：

| 文件 | 内容 |
| --- | --- |
| `settings.json` | 主题 / 并发 / 下载目录 / 免转存开关 |
| `tasks.json` | 下载任务与分片进度（续传依据） |
| `credentials.bin` | DPAPI 密文（凭证 + 元数据整体加密） |
| `bookmarks.json` | 收藏链接 |
| `parse_history.json` | 解析历史（上限 100 条） |

### 9.2 数据目录探测

按候选顺序**写探针文件**验证可写（`create` 成功不算，杀软可能放行建目录但拦写文件）：
程序目录 → `%APPDATA%` → `%LOCALAPPDATA%` → `Documents` → `TEMP` → `Downloads`。
落到 TEMP/Downloads 时界面显式提示「不持久化」。

## 10. 决策记录

| 编号 | 决策 | 理由 |
| --- | --- | --- |
| D1 | 平台范围 = 夸克 / UC / 123 云盘 | 与官方移动端主力一致，接口可自测 |
| D2 | 登录 = 应用内嵌浏览器 | 手贴 Cookie 对普通用户太难 |
| D3 | 技术栈 = Flutter 桌面 | 单代码库、原生 M3、包体远小于 JRE+CEF |
| D4 | 界面 = 纯 Material 3，浅色默认 | 「去 AI 味」：不要渐变/发光/夸张动效 |
| D5 | 视频解析一度下架、随后恢复并接上在线播放 | 下架后 media_kit 成了无入口的死重量；「先看再下」才是网盘工具该有的能力 |
| D6 | 平台图标不进仓库，本机脚本获取 | 商标风险；缺失时自绘色块兜底 |

## 11. 验收标准

1. 全新 clone → `flutter pub get && flutter analyze && flutter test && flutter build windows` 全绿。
2. 三家网盘各 1 条真实链接走通：粘贴 → 文件树 → 勾选 → 下载 → 文件在指定目录且可打开。
3. 未登录状态下免登录可用的路径不被登录拦截（R1）。
4. 关闭免转存后确实发生转存（自己的网盘里出现该文件）。
5. 杀软默认策略下：便携版解压即用，能完成一次真实下载。
