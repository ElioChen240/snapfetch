闪取 SnapFetch —— 粘贴网盘分享链接，直接高速下载
================================================

独立实现 · 非官方 · 开源 (AGPL-3.0)

【快速上手】
1. 启动「闪取 SnapFetch」（开始菜单 / 桌面快捷方式）
2. 「账号」页 → 选夸克 / UC / 123 云盘 → 登录（应用内完成，凭证仅存本机并 DPAPI 加密）
3. 「解析」页粘贴分享链接（带提取码的整段文案也可以；也可填右侧提取码框）
4. 勾选文件 → 「下载所选」→ 「下载」页看进度（支持暂停 / 继续 / 断点续传）

【设置】
- 下载分片并发数：1~32（大文件多线程加速）
- 下载目录：默认是你的「下载」文件夹；「选择文件夹」改到哪就存到哪，
  程序不会偷偷替换你设置的目录
- 免转存下载：默认开。开启时解析出直链就直接下载，不会把别人的文件
  转存进你自己的网盘；关闭后改为「先转存到你的网盘，再下载」
- 主题：跟随系统 / 浅色 / 深色

【收藏夹与解析历史】
- 「收藏」保存你主动存下的链接；「历史」自动记录每次解析（含失败原因），
  点击即可回填链接与提取码并重新解析

【WebView2 说明】
应用内登录依赖 Microsoft WebView2 Runtime（Win10/11 一般已内置）。
若启动后账号页提示缺失，请以管理员运行安装目录下的
MicrosoftEdgeWebview2Setup.exe，然后重启应用。

【数据与卸载】
- 用户数据（设置 / 加密凭证 / 任务 / 收藏 / 历史）默认写在
  程序所在目录的 SnapFetch-data 子目录（便携惯例，且实测未签名程序
  往用户目录写文件容易被部分杀软按进程拦截）。
- 卸载程序不删除该目录（保护你的凭证与任务）；彻底清除请手动删除。
- 若本机连程序目录也不可写，应用会降级到临时目录并在界面明确提示
  「本次不会持久化」，不会假装保存成功。

【安全软件提示】
本程序未做代码签名。火绒 / 360 等可能提示「未签名程序写入」或拦截
安装。这是杀软对未签名程序的通用行为，不是软件缺陷；将 SnapFetch.exe
加入信任区即可。若你选择放行，请自行确认来源（发布页附 SHA256 校验和）。
