闪取 SnapFetch —— 粘贴分享链接，直接高速下载
================================================

独立实现 · 非官方 · 开源 (AGPL-3.0)

【快速上手】
1. 启动「闪取 SnapFetch」（开始菜单 / 桌面快捷方式）
2. 「账号」页 → 选择平台 → 登录（应用内完成，凭证仅存本机 DPAPI 加密）
3. 「解析」页粘贴网盘分享链接或视频口令（整段文案均可）
4. 勾选文件 → 「下载所选」→ 「下载」页查看进度（支持暂停 / 继续）

【设置】
- 下载分片并发数：1~32（大文件多线程加速）
- 下载目录：默认未设置时使用系统临时目录，建议改为常存盘位置
- 主题：跟随系统 / 浅色 / 深色

【WebView2 说明】
应用内登录依赖 Microsoft WebView2 Runtime（Win10/11 一般已内置）。
若启动后账号页提示缺失，请以管理员运行安装目录下的
MicrosoftEdgeWebview2Setup.exe，然后重启应用。

【数据与卸载】
- 用户数据（下载任务 / 凭证 / 设置）位于：
  %APPDATA%\SnapFetch\data
  （若安全软件拦截写入，应用自动降级到临时目录，重启后恢复）
- 卸载程序不删除上述目录（保护你的凭证与任务），彻底清除请手动删除。
